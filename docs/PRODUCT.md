# CampusMind Product Brief

## Problem

College students typically split their academic workflow across:
- LMS portals
- calendars
- notes
- cloud drives
- group chats
- AI tools
- task managers

CampusMind aims to consolidate the highest-value parts of that workflow.

## V1 user

A college student managing multiple courses who wants:
- one place for tasks and deadlines
- clear study priorities
- course-level organization
- AI help based on their own notes/materials

## Core V1 features

### Dashboard
- upcoming deadlines
- course overview
- study activity
- priority suggestions

### Courses
- create and manage courses
- color/icon metadata
- term/semester grouping

### Tasks
- assignments
- exams
- projects
- due dates
- priority
- completion state

### AI study assistant
- upload notes/PDFs
- ask questions
- retrieve relevant course content
- answer with source references

## Later differentiators

- shared study spaces
- real-time collaboration
- personalized study recommendations
- calendar integration
- grade forecasting
- adaptive study planning
- mobile experience
- premium features
